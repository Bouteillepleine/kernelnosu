Default umount modules
The setting that actually hides su from apps — not queryable from shell
check manually
The real switch is root manager → Settings → "Umount modules by default" (in French: "Démonter les modules par défaut"). This is KernelSU's default app-profile value applied to any app that doesn't have its own profile override — it is what makes the su binary above invisible to ordinary apps, confirmed on a freshly-launched, never-configured app with no reboot needed.

This is not the same as "kernel_umount" / "Démontage du noyau" below — that's a different, lower-level feature and is not required for hiding su. We couldn't find a shell-readable way to query the default-umount-modules value live (it lives behind an ioctl the manager app calls directly), so check it in the manager's Settings page rather than trusting a status pill here.

Root is never affected by any of this — only non-su app processes lose the mount.
